## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/happy-531/My-First-Project.git
```

Open the project folder:

```bash
cd My-First-Project
```

Run the project you want using the appropriate compiler or interpreter.

### Python

```bash
python filename.py
```

### C

```bash
gcc filename.c -o program
./program
```

### PHP

Run using a local PHP server (e.g., XAMPP or PHP built-in server):

```bash
php -S localhost:8000
```
